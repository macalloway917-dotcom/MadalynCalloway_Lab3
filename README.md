# Tip Calculator
## Description
A simple C++ console program that calculates a tip percentage 
based off an initial price and displays the total after tip.
## How to Run
1. Open the project folder in Visual Studio.
2. Press Ctrl+F5 to build and run.
3. Enter price when prompted (must be >=0).
4. Enter percentage when prompted (must be >=0).
## Sample Input / Output
Input: Initial Price: 100 Percentage: 25%
Output: Tip Amount: $25 Total after tip: $125
